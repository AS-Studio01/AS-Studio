# VitalCare Multispecialty Clinic — portfolio concept

A standalone, responsive multi-page fictional healthcare website made for AS Studio's portfolio. It does not modify or include the AS Studio agency website.

## Pages
- `index.html` — Home
- `services.html` — Six fictional service areas
- `team.html` — Fictional clinician profiles
- `appointments.html` — Validated demo enquiry form
- `faqs.html` — FAQ accordion and safety wording
- `contact.html` — Fictional address, contact and hours

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required. Google Fonts and image URLs need an internet connection; system sans-serif fallbacks are included. The site itself uses vanilla HTML, CSS and JavaScript.

## Before adapting for a real clinic
1. Replace all fictional clinic, clinician, location, contact, schedule and service information with verified details.
2. Replace illustrative clinician and clinic imagery with properly licensed photos and written permission where needed.
3. Remove the concept banner only after the demo has been adapted and approved for the real provider.
4. Connect the form to a secure backend or trusted booking provider. Add server-side validation, spam protection, privacy notice, data retention rules and appropriate protection for personal/health data. The current form does not transmit or store anything.
5. Replace fictional schema data, title, description, Open Graph image, canonical URL and social links.
6. Have qualified clinical/legal reviewers approve all health information, claims and policies. This is not medical advice.
7. Verify keyboard access, screen reader labels, contrast, mobile layout and performance in target browsers before launch.

## Included functionality
- Responsive sticky navigation and mobile menu with Escape-key support
- Light/dark theme toggle with local preference
- Six specialty sections with appointment deep links
- Client-side required-field/email validation and clear demo result
- FAQ native disclosure accordion
- Focus-visible styles and reduced-motion support
- Basic Open Graph metadata and `MedicalClinic` JSON-LD using explicitly fictional data

## Important
VitalCare Multispecialty Clinic, the doctors, address, phone number, email, opening times, service offering and all profile descriptions are fictional placeholders. The page is a design concept, not a real clinic, booking system or source of medical advice. The contact details and map are not functional.

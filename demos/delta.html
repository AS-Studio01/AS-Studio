Built to be scripted against

Every action in the interface is an API call first. If you can click it, you can automate it.

create-ticket.sh 
# Create a ticket from a script
curl -X POST https://api.delta.example/v1/tickets \
  -H "Authorization: Bearer $DELTA_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "project": "website-rewrite",
    "title": "Checkout drops the cart on refresh",
    "assignee": "ak",
    "labels": ["bug", "checkout"],
    "estimate_minutes": 90
  }'

Webhooks for every change

Ticket created, moved, assigned, commented or closed — each fires a signed POST. Retries with exponential backoff for 24 hours.

Predictable pagination

Cursor-based, stable ordering, 100 items per page. Your integration does not break when someone else's data changes mid-scroll.

Import from anywhere

CSV, Trello, Asana, Linear and GitHub Issues importers. Bring your tickets across in an afternoon, not a weekend.

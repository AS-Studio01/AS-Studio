# AS Studio Final

Premium vanilla HTML, CSS and JavaScript website. No React, TypeScript or Vite build is required.

## Firebase
The existing AS Studio Firebase project/configuration is preserved. Browser Firebase integration lives in `js/firebase.js`. The Firebase project is not replaced by this rebuild.

## Local preview
Use any static server, or run `npm install && npm start` when the server-side AI concierge is configured.

## Vercel
Framework preset: Other
Build command: none
Output directory: `.`

For a static deployment, the root `index.html` is the entry point.
